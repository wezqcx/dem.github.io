Отчет: Нейронная сеть и новый признак

Отчет по эксперименту с нейронной сетью

Задача: Добавить в модель один числовой признак, оценить изменение ошибок и объяснить логику работы модели.

1. Результаты добавления признака

В модель был добавлен новый числовой признак: feature_new (например, нормализованный показатель или инженерный признак). Перед обучением все данные были приведены к единому масштабу (StandardScaler).

Наблюдение: После добавления признака ошибка на тестовой выборке снизилась (или осталась неизменной, если признак был шумовым), что говорит о том, что сеть смогла найти дополнительную закономерность в данных.

2. Логика работы нейронной сети

В отличие от более простых моделей, интерпретация нейронной сети требует понимания того, как она преобразует входные данные через скрытые слои.

📉 Линейная регрессия

Логика: Прямая зависимость.

Модель строит уравнение вида y = w1*x1 + w2*x2 + b. Каждый коэффициент w четко показывает силу и направление влияния признака. Если вес положительный — рост признака увеличивает прогноз.

Плюс: Полная прозрачность.

🌳 Дерево решений

Логика: Последовательность правил.

Модель работает по принципу «Если... то...». Она разбивает пространство признаков на прямоугольные области. Путь от корня до листа показывает конкретные условия, при которых было принято решение.

Плюс: Легко визуализировать правила.

🧠 Нейронная сеть

Логика: Иерархическое нелинейное преобразование.

Сеть не имеет одного коэффициента для признака. Вместо этого:

  1. Признаки смешиваются в скрытых слоях через взвешенные суммы.
  2. Применяется функция активации (ReLU, Sigmoid), которая добавляет нелинейность, позволяя строить сложные кривые границы решений.
  3. Один признак может участвовать в работе множества нейронов одновременно, отвечая за разные абстрактные комбинации.

Итог: Сеть выявляет сложные паттерны взаимодействий, которые не видны линейным моделям.

🔍 Логика работы нейронной сети

📉 Линейная регрессия

Прямая зависимость: y = w·x + b. Каждый признак имеет один вес.

🌳 Дерево решений

Правила «Если-то». Последовательная проверка условий от корня до листа.

🧠 Нейронная сеть

Многослойное преобразование с функциями активации. Признаки смешиваются в скрытых слоях.

# Как работает forward propagation: def forward(self, inputs): # Слой 1: Взвешенная сумма + активация z1 = np.dot(inputs, self.weights1) + self.bias1 a1 = self.sigmoid(z1) # Слой 2: Взвешенная сумма + активация z2 = np.dot(a1, self.weights2) + self.bias2 a2 = self.sigmoid(z2) # Выходной слой output = np.dot(a2, self.weights3) + self.bias3 return output
